# OBJETIVO

Analizar todas las ambigüedades, dudas y preguntas abiertas identificadas durante la fase de análisis.

NO debes eliminarlas.

Debes transformarlas en decisiones explícitas o supuestos documentados para permitir continuar el diseño.

# REGLAS

Para cada ambigüedad:

1. Identificar el problema.
2. Explicar por qué bloquea o afecta el diseño.
3. Proponer entre 1 y 3 alternativas viables.
4. Recomendar una alternativa.
5. Justificar técnicamente la recomendación.
6. Evaluar riesgos.
7. Registrar el nivel de confianza:

   * Alto
   * Medio
   * Bajo

# IMPORTANTE

* No afirmar que la recomendación es la única solución.
* No presentar el supuesto como un hecho confirmado.
* Todo supuesto debe quedar marcado explícitamente.
* Si la información es insuficiente, indicar que el riesgo permanece abierto.
